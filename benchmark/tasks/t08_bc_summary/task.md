# Breast cancer summary statistics

How many tumors in the breast cancer data are malignant, and what is the average
`mean_radius` for malignant and for benign tumors? Check notes.txt for the label coding.

The data files are in the `data/` folder of the current working directory.

At the end, your program must print exactly one line that starts with `ANSWER:` followed by a JSON object with these keys:

- `n_malignant`: number of malignant tumors
- `mean_radius_malignant`: average mean_radius of malignant tumors
- `mean_radius_benign`: average mean_radius of benign tumors
