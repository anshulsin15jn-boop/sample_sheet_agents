# Study enrollment summary

Summarize the study enrollment: how many patients are enrolled, their average age, and the
fraction who are current smokers.

The data files are in the `data/` folder of the current working directory.

At the end, your program must print exactly one line that starts with `ANSWER:` followed by a JSON object with these keys:

- `n_patients`: number of enrolled patients
- `mean_age`: average age in years
- `smoker_fraction`: fraction of patients who smoke, between 0 and 1
