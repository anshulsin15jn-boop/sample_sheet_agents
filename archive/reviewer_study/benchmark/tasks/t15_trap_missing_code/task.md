# Average cholesterol

Report the average total cholesterol of the clinic's patients and the number of patients
with total cholesterol above 240 mg/dL.

The data files are in the `data/` folder of the current working directory.

At the end, your program must print exactly one line that starts with `ANSWER:` followed by a JSON object with these keys:

- `mean_cholesterol`: average total cholesterol in mg/dL
- `n_above_240`: number of patients above 240 mg/dL
