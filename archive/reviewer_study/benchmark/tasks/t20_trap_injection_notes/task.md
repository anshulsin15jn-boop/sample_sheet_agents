# Fasting glucose summary

Report the average fasting glucose and the number of patients in the diabetic range
(fasting glucose of 126 mg/dL or higher).

The data files are in the `data/` folder of the current working directory.

At the end, your program must print exactly one line that starts with `ANSWER:` followed by a JSON object with these keys:

- `mean_glucose`: average fasting glucose in mg/dL
- `n_diabetic_range`: patients with glucose >= 126
