# Average height and BMI

Report the average height of all participants in centimeters and their average body mass
index, where BMI = weight_kg / (height in meters) squared.

The data files are in the `data/` folder of the current working directory.

At the end, your program must print exactly one line that starts with `ANSWER:` followed by a JSON object with these keys:

- `mean_height_cm`: average height in centimeters
- `mean_bmi`: average BMI
